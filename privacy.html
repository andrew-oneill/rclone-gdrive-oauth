Privacy policy

Last updated: 21 October 2026

Who uses this app

This OAuth client is used only by its owner, to access the owner's own Google account. It is not offered to the public.

What data is accessed

The app requests the Google Drive scope (https://www.googleapis.com/auth/drive) so that rclone can list, read, create, modify and delete files in the owner's Google Drive.

How data is used and stored

Files are transferred directly between Google Drive and the owner's own computer. Opened files and OAuth tokens are stored only on that computer. No data is sent to, or stored on, any other server.

Sharing

No data is sold, shared with or disclosed to any third party, and no data is used for advertising, analytics or training machine-learning models.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from Google Account → Third-party connections.
